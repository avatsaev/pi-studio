# Task 004 — Benchmark: the bridge candidates — Summary

- **Completed:** 2026-11-21
- **Status:** done

## What was implemented
In `desktop/apps/ipc-bench/`: a bridge mode in which Rust holds a client socket to the benchmark's own server and forwards between it and the page.
- `src/bridge.rs`, `src/bridge_commands.rs`: inbound over a Tauri `Channel` in two variants (`frame`: one message per WebSocket message, raw for binary and JSON for text; `batch`: the `net` codec's batches, flushed at 64 KiB or when the socket has nothing more); the `net` crate's `InboundWindow` (stop above 8 MiB, resume below 4 MiB) and `OrderBuffer` (outbound `seq` order); one write task, one flush per queued group. Commands `bridge_open`, `bridge_send_text`, `bridge_send_binary` (raw body with `handle` and `seq` headers), `bridge_send_batch`, `bridge_ack`, `bridge_close`, `bridge_stats`.
- Page: `page/bridge.js` (one transport behind task-002's interface; options `{inbound, outbound, ack}`; acknowledgements every 256 KiB or 50 ms; `bufferedAmount` added at send and subtracted at the answer; `ack: false` is the no-acknowledgement mode), `page/batch.js` (codec mirror), `page/compare.js` (a first reading against P1), three transports (`websocket`, `bridge-frame`, `bridge-batch`), B2 also at 256 KiB (baseline too), a new workload W1 (`--only window`: a 128 MiB flood never acknowledged; Rust must hold just past 8 MiB and the server must stall; then acknowledge and require the flood whole), B5 reads `bufferedAmountEnd` once the answers settled (a report can overtake them). `results.json` is schema 2.
- Recorded per run: whether raw bodies reached Rust as bytes or as a JSON array, sends out of `seq` order and the most frames waiting, channel messages evaluated into the page versus fetched, the window's numbers.
- Files: `src/{bridge.rs,bridge_commands.rs}` (new), `src/{main.rs,server.rs}`, `build.rs`, `capabilities/default.json`, `permissions/autogenerated/bridge_*.toml` (7), `page/*` (new: batch, bridge, compare and three tests), `desktop/docs/development.md`, `desktop/AGENTS.md`, `desktop/README.md`, `desktop/docs/architecture.md`. No new external crate.
