## What was implemented
- **Save state, `crates/shell/src/saves.rs`** (`#[cfg(not(target_arch = "wasm32"))]`):
  - `Saves::open(config_dir, downloads)` runs the launch cleanup.
  - `begin(destination)` creates the temporary file beside the destination and returns a handle. The handle is 128 random bits as 32 hex digits, single use, with at most 8 open (`MAX_OPEN`).
  - `write` appends, at most 16 MiB per call (`MAX_WRITE_BYTES`).
  - `finish` does `sync_all` and then renames over the destination. If either step fails, the temporary file is removed and the handle is spent.
  - `discard` removes the temporary file.
  - `choose(services, suggested)` calls the dialog hook and then `begin`.
  - An unknown, finished or discarded handle is `UnknownHandle`. Error texts never contain a path.
- **Temporary file:** `.pistudio-save-<32 hex>.part`, created with `create_new`, so the final file gets the normal umask permissions and not 0600.
- **Journal:** `pending-saves.json` in the config directory lists the temporary files of open saves.
  - It is written before the file is created.
  - It is rewritten after finish or discard.
  - If the journal cannot be written, `begin` fails and no file is left.
  - At launch the listed files are removed and the journal is emptied. Only files named like a temporary save file are removed, so a damaged journal cannot delete anything else.
  - A missing journal creates no file. A corrupt journal is set aside by the store.
- **Clean shutdown:** a `Drop` on each save removes its temporary file.
- **Suggested name:** `file_name()` keeps the last path segment (split at `/` and `\`, skipping `.` and `..`). It strips control characters, trims whitespace, cuts to 255 bytes on a character boundary keeping an extension of up to 32 bytes, and falls back to `download`.
- **Service hook:** `Services.pick_save_path: Option<PickSavePathHook>` takes the name and the starting folder, and returns a path or `None` when cancelled.
  - The starting folder is the last destination folder in this run, kept in memory, else Downloads (`app.path().download_dir()`).
  - The native hook in `src-tauri/src/services.rs` uses the dialog plug-in's `save_file`. It shares the one-dialog-at-a-time lock, brings the window forward and sets the parent.
- **Page commands:** `save_begin`, `save_write`, `save_finish`, `save_discard`, added to `build.rs`, `capabilities/default.json` and `generate_handler!`. All file work runs through `spawn_blocking`.
  - `save_begin({ suggestedName })` returns `{handle}` or `null`.
  - `save_write` takes the raw body, with the handle in the **`handle` request header**. Task-007 must send the chunk as `invoke("save_write", bytes, { headers: { handle } })`.
  - A chunk over 16 MiB is refused before it is copied to the writing thread.
  - `save_finish({handle})` and `save_discard({handle})` return nothing.
