# Task 003 — Preview origin (Rust) — Summary

**Sprint:** sprint-105-desktop-html-preview-origin
**Completed:** 2026-11-20
**Status:** Done. `cargo xtask ci` passes, including `cargo test`, clippy and the wasm check.

## What was implemented
- **Document store** (`shell::preview::Previews`):
  - `mount(html)` returns an id of 128 random bits as 32 lowercase hex characters.
  - `get`, `release`, `release_url` and `clear` are there too.
  - A mount is refused beyond 32 documents or 32 MiB total, and a refused mount keeps nothing.
  - On wasm32 the id source is stubbed to an error, so the wasm check still builds.
- **Pure serve core** (`Previews::serve(method, path)`):
  - A `GET` of a mounted id answers 200 with the four headers: `Content-Type: text/html; charset=utf-8`, `Content-Security-Policy: sandbox allow-scripts`, `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`.
  - Any other id, path or method answers 404.
  - The 404 carries `Content-Security-Policy: sandbox`, `no-store` and `nosniff`, with an empty body.
- **Platform table**: `kind_for(os)` and `kind()` return `Origin` for linux and `Inert` for everything else.
- **URL form**: one form only, `pi-preview://localhost/<id>`. The Windows form is not built, since Windows is unmeasured and `inert`.
- **Boot snapshot**: it now carries `preview: "origin" | "inert"`. The `boot` command clears the store first, so documents do not outlive a page reload.
- **Commands** `preview_mount {html}` and `preview_release {url}`:
  - `preview_mount` answers `{url}`, and errors on an inert platform or when a cap is hit. The error text never echoes the document.
  - `preview_release` ignores an unknown or foreign URL.
  - Both are in `build.rs`, `generate_handler!` and the capability file, which now lists 12 permissions. The capability description is reworded.
- **Scheme handler**: new `src-tauri/src/preview_scheme.rs` adapts the serve core to Tauri's request and response types. `main.rs` registers the `pi-preview` scheme and manages `Previews`.
- **Policy**:
  - `tauri.conf.json` gets `"frame-src": ["pi-preview:"]`, the form the spike measured.
  - `navigation::allows` now admits exactly `pi-preview://localhost` with no port, case-insensitively. This is needed because WebKitGTK runs the guard for subframes. Its doc comment no longer says "Frames are not covered".
  - No capability names the origin.
