# Task 001 — App binary: `transport_open`, the proxied connections, closing on boot and switch — Summary

- **Sprint:** sprint-116-desktop-bridge-wiring
- **Completed:** 2026-11-22
- **Status:** done

## What was built
- Command `transport_open { url }` → `{ localUrl }`, errors `{ code, message }`; in `build.rs`, `capabilities/default.json` (`allow-transport-open`), `generate_handler!`; generated `permissions/autogenerated/transport_open.toml`. App wiring in `src-tauri/src/transport.rs`, `commands.rs`, `daemons.rs`, `main.rs`.
- Order as the spec's pseudocode: one question to the owner thread; `not_bridged`, `address_mismatch`, `invalid_address`, `limit`; the calling webview's origin; the password on the blocking pool (`secret_missing`, `secret_unavailable`); the dial within 15 s; `Reservation::open`.
- `boot`, `daemon_switch` (after the confirm, before the reload), the window's `Destroyed` event and the app's `Exit` close every proxied connection (daemons see 1001).
- The existing `plan_dial` carries no entry id and cannot tell a relay entry apart, so one message was added in `engine` and `shell`: `Session::plan_bridge` → `BridgePlan` (entry id, address, where the password lives), carried by `LocalOp::Bridge`; `OwnerAccess::{bridge_plan, bridge_password}`. `net::check_address` refuses a bad address before a place is reserved or a secret read.
- New code `local_not_ready` (local daemon being started or needing a start); other local states pass through `daemon_resolve_current`'s codes. Spec error table amended.
