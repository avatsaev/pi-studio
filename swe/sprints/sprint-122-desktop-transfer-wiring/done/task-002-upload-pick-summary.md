## What was implemented
- **Hook:** `Services::pick_files` (`PickFilesHook`, `Fn(Option<&Path>) -> Vec<PathBuf>`). An empty list means cancelled, no plug-in, or a non-path answer.
- **Dialog (app):** `Native::pick_files` in `src-tauri/src/services.rs`.
  - It shares the one-at-a-time lock with the other dialogs.
  - It brings the window forward and is parented to the main window.
  - It starts in the folder given and uses the non-blocking `pick_files` callback.
- **Table:** new `shell::picked` module (native only).
  - `Picked::pick(&Services)` answers `PickedFile { handle, name, size? }`.
  - The handle is `random_hex(16)`, 32 lowercase hex digits.
  - `name` is the lossy last component. `size` is set only when the metadata can be read and the path is a file. A path with no file name is skipped.
  - The table holds at most 1024 unused entries and drops the oldest. A single dialog answer over 1024 gets handles only for its newest 1024.
  - `Picked::take(handle) -> Option<PathBuf>` is the single-use call for a later task.
  - `Picked::clear()` drops all entries. The last folder is kept.
  - The dialog starts in the folder of the first file of the last non-empty pick in this run.
  - `PickedFile` serializes as `{handle, name, size?}`; `size` is left out when unknown.
- **Command:** `upload_pick`. Under `--transfers page` it answers `engine_off` before any dialog. Otherwise it picks off-thread. Errors are `{code, message}`: `engine_off`, `unavailable` (no hook), `internal`.
- **Mode lookup:** the command reads a Tauri-managed `TransfersMode`, set in `main.rs` from `args.transfers`. `boot` clears the picked table.
- **Registration:** the command is in `build.rs`, in the capability as `allow-upload-pick`, and in `generate_handler!`. The capability description and the `commands.rs` header now say seventeen commands.
- **Shared code:** `saves::random_hex` is now `pub(crate)` and returns `getrandom::Error`. `SaveError` gains `From<getrandom::Error>` with the same text as before.
- **Error type:** `TransferFailure { code, message }` is new in `src-tauri/src/transfers.rs`.
