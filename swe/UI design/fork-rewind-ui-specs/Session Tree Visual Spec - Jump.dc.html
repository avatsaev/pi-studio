TOASTS AND RECOVERIES
◈An extension declined the navigation.
Dialog closes, nothing moved. No retry button — a declining extension will decline again.
!Couldn't write the summary. Nothing moved.
Dialog stays open and returns to idle with the user's radio choice intact, ready to retry or switch to "No summary". The second sentence is required — the engine guarantees it and the user needs to hear it.
⟳The tree moved on. Refreshed — pick again.
Stale tree: dialog closes, pane refetches in place, scroll position preserved, the row the user aimed at gets a 1.2s accent flash if it still exists.
AGENT BUSY · PANE BANNER, STATED ONCE
Agent is working — navigation is paused. Browsing still works.
Sits under the pane header, above the filter row. Appears and disappears with the transcript's own running-turn bar, from the same state. Rows keep full contrast and stay scrollable, foldable and focusable; only the click-to-jump and the ⑂ action are withheld.
DECISION · CONVERGENCE IN OTHER WINDOWS — handover Q6, answers the same question for fork
Other windows refresh silently — no toast, no banner, no highlight. A toast in a window the user isn't looking at is noise when they return, and a toast in a window they are looking at explains a change they just made themselves. The one concession: a transcript whose content shrinks animates the truncation with a 180ms fade rather than snapping, so a watching user sees that something happened. Open tree panes in other windows refetch on the same signal and keep their scroll position.
