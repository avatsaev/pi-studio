PI-STUDIO · VISUAL SPEC · CONVERSATION FORK

Fork — rewind a conversation to an earlier user message

This spec is split by concern — open only the part you are building. Section numbers (§00–§14) are stable and are what the technical spec cites; every mock is real DOM at final size, styled with the app’s own custom properties. Hex appears once, in §01. Measurements in the anatomy blocks are normative; anything not stated inherits the existing component default.

The five open questions in the handover doc are decided here (§02, §04, §07, §09, §10) so implementation has one answer each. Where a decision could reasonably go the other way, the rejected option is named. Companion spec: Session tree — the map of everywhere this conversation has been, which inherits this spec’s dialog, toast and confirm patterns verbatim.
