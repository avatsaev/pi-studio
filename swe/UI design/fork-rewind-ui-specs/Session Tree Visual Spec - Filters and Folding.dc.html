FIVE VIEW FILTERS · SEGMENTED, RESET ON EVERY OPEN
Default No tools User only Labeled All
Segmented at ≥380px; collapses to a Select below that. Five labels fit — "Labeled only" shortens to "Labeled" in the segment, full text in the Select and in aria-label.
Pure view filtering. Hidden nodes never change the tree's shape: a filtered-out parent's children reparent visually to the nearest visible ancestor, keeping depth columns for the surviving levels only.
Filter state is per-open, never persisted. User only is the headline mode and the one to get right first: it turns the tree into a table of contents of the user's own prompts.
The active path and the leaf marker survive every filter. If the leaf itself is filtered out, its nearest visible ancestor takes a CURRENT ↓ variant of the chip.
DECISION · FOLDING SHIPS IN V1
Filters alone don't solve the branchy case: "User only" still shows every abandoned prompt, and that's precisely the noise a user scrolling for their current work wants gone.
Default fold state: abandoned branches deeper than one row are folded; the active path is always fully expanded and cannot be folded shut.
Fold row: replaces the branch's children with a single ⊕ row reading "n entries collapsed", plus the branch's first user prompt when it fits. Click anywhere on the row expands.
Unfold is sticky per node for the life of the pane, and resets with the pane.
Chevron affordance: none. The fold row is the whole control — a separate 12px chevron on 300 rows is clutter for an action with one obvious target.
DECISION · ORIENTATION IN A 300-NODE TREE — handover Q4
1 · Open scrolled to the leaf
The pane scrolls so the leaf sits about two-thirds down, with its ancestors above it. Not centred — the interesting history is upward.
2 · "Jump to current" pill
↓ Jump to current
Bottom-centre of the list, appears only when the leaf is scrolled out of view, direction arrow follows. Scroll only — it never navigates.
3 · Rejected: minimap
Costs a column, needs its own hit model, and answers a question ("how big is this?") nobody asked. Two cheap mechanisms cover the real need.
