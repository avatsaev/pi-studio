13Edge cases & failure matrix
CASE
BEHAVIOUR
Hover target ambiguous
Open the dialog on step 1 (picker) instead of guessing. No error, no explanation.
Session not yet saved
Toast; dialog returns to idle
Two people fork nearly simultaneously
Second attempt fails with the stale-entry toast; that window has already converged to the first fork, so its picker list is correct on reopen
Turn starts while the dialog is open
Dialog stays open; confirm disables with the tooltip "Not while a turn is running"
Very long single message
2 lines in the picker, 3 in the preview, ellipsis; never unbounded, never scrollable inside the preview
Message is only an image, no text
Preview shows the muted placeholder "(image only)"; composer prefill is skipped
Composer holds a draft
No prefill, no prompt, no toast — the fork still succeeds
