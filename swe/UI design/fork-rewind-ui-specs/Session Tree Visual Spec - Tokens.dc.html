FIVE NEW PRIMITIVES — THE ONLY NEW VOCABULARY THIS FEATURE ADDS
Guide rail — 1px surface3 vertical at x=7 of each 16px depth column. On the active path it thickens to 2px and takes accentBright at 45%.
Elbow — the node's own column: vertical from row top to y=15, then 1px horizontal to the disc. Same colors as the rail.
Disc — 18px, matching the transcript. Kind glyph inside. Active-path discs get a 1px accentBright ring at 55%.
Leaf marker — the current position only: a "current" chip and a solid accentBright disc fill. Never more than one per tree.
Label chip — 16px pill, surface3 fill, 10.5px text, prefixed ◇. Display-only.
