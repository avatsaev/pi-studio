Cancel Forking…
Both buttons disabled. Outside-click and Esc are inert until the call settles. No timeout UI — the request either resolves or errors.
FAILURE PATHS
Error. Dialog returns to idle with the preview intact; the message surfaces on the app-wide toast host. The same dialog instance is reusable — the user can press Fork again without re-selecting.
Declined by an extension. The dialog closes and nothing in the transcript changes; a single toast explains why. Retrying is a fresh invocation, not a retry button.
