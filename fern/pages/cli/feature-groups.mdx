---
title: Feature Groups
subtitle: Terminals, providers, and worktrees.
---

`terminal`, `provider`, and `worktree` are sibling
top-level command groups — there is no `feature` wrapper, and no `project` group (opening a
project is the top-level `pi-studio <path>` command, see [Quickstart](/quickstart#target-a-remote-daemon)).

| Group | Commands |
|---|---|
| `terminal` | `ls`, `create [--workspace] [--cwd]`, `capture <slot>`, `send-keys <slot> <data>`, `kill <slot>` |
| `provider` | `ls`, `models <providerId>` |
| `worktree` | `create <name> [--workspace]`, `ls`, `archive <name>` |

Run `pi-studio <group> --help` for a live listing of every flag on a given group's commands.
